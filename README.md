# サッカーやるよん
サッカーゲームです。初めて作りましたが、遊んでくれると嬉しいです！

---


自分のサイトに置く版です。だれでも次のことができます。
- ルームコードを打つだけでの即対戦
- アカウントへの自動保存
- スマホのホーム画面へのインストール

使うものは2つで、どちらも無料です。
- **Firebase（Google）**：ログインとデータ保存
- **GitHub Pages**：ゲームを置く場所

パソコンで作業するのがおすすめです。全部で15〜30分ほどかかります。

---

## A. Firebase の準備

### 1. プロジェクトを作る
1. https://console.firebase.google.com を開き、Googleアカウントでログインする
2. 「プロジェクトを作成」を押す
3. 名前（例：`soccer-yaruyon`）を入れて進む
4. Googleアナリティクスは「オフ」でよい
5. 「プロジェクトを作成」を押す

### 2. ログインの方法を有効にする
1. 左のメニューで「構築」→「Authentication」→「始める」を押す
2. 「ログイン方法」タブで次の2つを有効にする
   - **匿名**：オンにして保存する（ゲストとしてすぐ遊べるようになる）
   - **Google**：オンにし、サポート用メールに自分のアドレスを選んで保存する

### 3. データベースを作る
1. 左のメニューで「構築」→「Firestore Database」→「データベースの作成」を押す
2. ロケーションは **asia-northeast1（東京）** を選ぶ
3. 「本番環境モード」を選んで「作成」を押す
4. 「ルール」タブを開き、中身を全部消す
5. このフォルダの `firestore.rules` の中身を全部貼り付けて「公開」を押す

### 4. 設定の文字列をもらう
1. 左上「プロジェクトの概要」の横の歯車→「プロジェクトの設定」を開く
2. 下の「マイアプリ」で「</>」（ウェブ）を押す
3. アプリのニックネームを入れて「アプリを登録」を押す（Hosting はチェックしなくてよい）
4. `const firebaseConfig = { ... };` が表示されるので、`{ }` の中身をコピーする
5. このフォルダの `firebase-config.js` を開き、`{ }` の中身を置き換えて保存する

`apiKey` などは公開されても大丈夫な値です。データはルールで守られています。

## B. GitHub Pages に置く

### 5. 置き場所を作る
1. https://github.com でアカウントを作ってログインする
2. 右上の「＋」→「New repository」を押す
3. 名前（例：`soccer-yaruyon`）を入れ、**Public** を選んで「Create repository」を押す

### 6. ファイルを入れる
1. 「uploading an existing file」を押す
2. このフォルダの中身を全部ドラッグする（`icons` フォルダごと入れる）
   - index.html
   - fb.js
   - firebase-config.js
   - sw.js
   - manifest.webmanifest
   - firestore.rules
   - icons/
3. 「Commit changes」を押す

### 7. 公開する
1. リポジトリの「Settings」→「Pages」を開く
2. Branch で `main`、`/(root)` を選んで「Save」を押す
3. 1〜2分たつと、上に次のようなURLが出る
   `https://（ユーザー名）.github.io/soccer-yaruyon/`

---

## C. 仕上げ

### 8. FirebaseにURLを許可する（Googleログインに必要）
1. Firebase の「Authentication」→「設定」→「承認済みドメイン」を開く
2. 「ドメインを追加」を押す
3. `（ユーザー名）.github.io` を入れて追加する

### 9. 動作確認
1. 7のURLを開き、「記録」タブの一番下を見る
   - 「ゲストとして保存中」と出ればつながっている
   - 「オフライン」と出たら、4の貼り付けをもう一度確かめる
2. 「対戦」→「ルームを作る」でコードを出す
3. 別のスマホでURLを開き、コードを入れて試合ができればOK

### 10. 友達に配る
URLを送るだけで遊べます。アプリのように使うには、ホーム画面に追加してもらいます。
- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：︙ →「アプリをインストール」（または「ホーム画面に追加」）

---

## よくあること
- **Googleログインがうまくいかない**
  - 8を忘れていないか確かめる
  - ホーム画面のアプリの中でうまくいかないときは、SafariやChromeで開いてログインする
- **ゲームを直したあと**
  - 新しい `index.html` をアップロードし直す
  - `sw.js` の `yaruyon-v1` を `v2` に変える（古い画面が残らないように）
- **無料の範囲**：Firebase の無料プラン（Spark）は1日に読み込み5万回・書き込み2万回まで。友達どうしで遊ぶ分には十分です。
- **データの場所**
  - Googleでログインした人：どの端末でも同じデータで遊べる
  - ゲストのまま遊ぶ人：その端末だけに保存される
